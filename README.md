# JavdbFusion

JavdbFusion 是面向 JAVDB 的 Tampermonkey 用户脚本，融合 Emby 风格界面、Emby/Jellyfin 媒体库联动、预告片播放和磁力工具。

当前版本：**7.369-trailer-diag**

## 功能

### 界面与导航

- **Emby 风格皮肤**：经典 / 毛玻璃 / 液态玻璃三套视觉，支持封面展现方式（裁切 / 全封面 / 融合 / 混合）与展示布局（标准网格 / 瀑布流 / 动态聚焦）。
- **详情页选项卡面板**：详情页内容切分为 `概览 / 磁力 / 短评 / 相关清单 / 磁力聚合` 五个页签，磁力 / 短评 / 相关清单直接驱动 JAVDB 原生的 movie-tab 组件，不与站点自身的 Stimulus 控制器冲突。
- **详情页锚点导航**：右侧边缘窄轨式导航，当前页签高亮，悬停展开文字。
- **首页视图切换栏**：`主页 / 收藏夹 / 预览画廊 / TOP250` 一级导航固定在内容列顶部并吸顶，与原生分类栏、筛选条保持同一左基线。
- **状态优先级统一**：卡片封面左上角只挂一枚状态角标，优先级 `已入库 > 已收藏 > 已观看 > 想看 > 有评分`，不再各模块各挂各的。
- **可读性**：卡片标题 / 评分 / 日期 / 标签的对比度均达到 WCAG AA（≥4.5:1），字号在 1440px 桌面上上调一档。
- **收藏管理**、TOP250 / 热播榜入口、评论与清单加载、演员与影片信息、筛选、快捷搜索、无缝翻页等。

### Emby / Jellyfin 联动

- 配置多个媒体服务器、同步本地媒体索引，在影片详情与列表中显示入库状态。
- 列表卡片支持预告片预览与媒体库搜索 / 播放。

### 预告片

- 整合 JAVDB 官方预告片、DMM/FANZA 多画质、厂商直链（加勒比 / 一本道 / HEYZO / 东京热）、javspyl 等来源，提供内嵌播放器、画质记忆与音量记忆。
- 番号对应的 DMM content_id 采用多种补零形态并发试探（5 / 6 / 7 位 + 厂牌变体），命中率高。
- **解析失败分类诊断**：区分「DMM 拒绝请求（限流 / 需要 Cookie / 地区）」「该番号在 DMM 没有商品」「DMM 没有该作品的预览视频」「地区限制」「网络错误」「已找到片源但全部播放失败（防盗链）」，并给出可对症的建议与可展开的诊断明细。

### 磁力工具

- 复制精简磁力链接、qBittorrent 与 115 离线推送、whatslink 验车。
- **磁力聚合**：Sukebei / BT4G / BTDigg / U9A9 / BTSOW 五源并发聚合去重，标题标注来源，支持按大小 / 做种数 / 智能排序。
- **115 整理改名**：离线后整理面板，一键清理垃圾文件（0 字节 / 样片 / 广告 / readme）、按模板一键规范改名、按模板归入目录。模板支持 `${code}` `${actor}` `${maker}` `${series}` `${title}` `${suffix}` `${crack}` `${res}`。

### 性能与无障碍

- **低特效模式**（设置 → 外观与显示）：关闭全部过渡动画与毛玻璃特效，显著降低滚动 / 切换的 GPU 与样式重算开销；系统开启「减少动态效果」时自动生效。
- 全局 GET 请求去重（并发合并 + 短期响应备忘），大体积索引只下载一次并跨会话持久化。

## 安装

1. 在 Chrome、Edge 或 Firefox 安装 Tampermonkey。
2. 打开 [GitHub Raw 脚本文件](https://raw.githubusercontent.com/huai3/JavdbFusion/main/JavdbFusion.user.js) 安装 —— 脚本的 `@updateURL` 指向同一地址，装好后可直接收到更新。
3. 安装后访问 JAVDB，打开脚本设置并按需启用功能。

> 如果同时启用了另一款会重做 JAVDB 页面样式的用户脚本，可能出现界面冲突；遇到问题时请先停用重复的皮肤脚本。

## 配置

### Emby / Jellyfin

打开脚本的「融合扩展设置」→「媒体库」→「添加服务器」，选择服务器类型并填写服务器地址和 API Key。点击「测试连接」后可同步索引。API Key 请在自己的媒体服务器中创建，不要提交到仓库或公开分享。

### 磁力与 115

「融合扩展设置」→「磁力工具箱」中配置 qBittorrent WebUI、115 目录 CID，以及 115 整理的目录 / 文件名 / 文件夹名模板与「离线后整理」开关。磁力聚合的源站选择与排序在详情页磁力条上。

### 其他服务

账号、密码、API Key 和令牌由用户脚本管理器在本机保存；不要将个人配置导出并上传。

## 权限与隐私

- 脚本需要在 JAVDB 页面运行，并通过用户脚本管理器的请求接口连接脚本功能所需的站点、已配置的媒体服务器及相关服务。
- 连接媒体服务器时，浏览器会向你配置的服务器发送影片番号查询或索引请求，并使用你填写的 API Key 鉴权。
- 不要把带有个人 API Key、密码、登录令牌、内网地址或个人媒体信息的配置文件、日志、截图发布到公开仓库。

## 常见问题

- **媒体库按钮显示搜索而不是播放**：确认服务器已启用、API Key 有效，并在设置中同步索引；列表页也会对屏幕附近的影片按需查询。
- **Jellyfin 详情链接无法打开**：先在媒体库设置中测试连接并确认服务器地址可从当前浏览器访问。
- **预告片提示「DMM 拒绝了请求」**：这是 DMM 侧限流或需要 Cookie，不是该番号没有片源；等几分钟重试，或改用其它网络出口。
- **预告片提示「已找到片源但全部播放失败」**：片源地址是对的，通常被防盗链（Referer）或地区限制挡住，可在源站打开再试。
- **页面滚动发涩**：在「设置 → 外观与显示」打开「低特效模式」，或系统开启「减少动态效果」。
- **更新后界面没有变化**：在 Tampermonkey 中确认脚本版本已更新，然后刷新 JAVDB 页面。
